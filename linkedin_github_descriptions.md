## ✅ INTERVIEW TALKING POINTS

**"Tell me about a project you've done":**
"I built an end-to-end HR analytics project where I analysed employee attrition data for 1,470 employees.
I started with data cleaning and exploratory analysis in Python, which revealed that employees doing overtime
were nearly 4× more likely to leave. I then wrote SQL queries to quantify the business cost — about ₹2.3 crore
in annual replacement costs for one department alone. I trained a Random Forest model to predict which employees
are at highest flight risk with an AUC of 0.73, and packaged the whole thing into a Power BI dashboard
HR managers can use to take proactive action. The key thing I'm proud of is that every output tied back
to a real business decision, not just numbers."

**"What tools do you use?":**
Python for analysis and modelling, SQL for structured querying, Power BI for dashboards,
and Excel for quick stakeholder summaries. I chose them because they're the exact stack most
Chennai IT and GCC companies use for analyst roles.

**"How did you validate your model?":**
"I used an 80/20 train-test split with stratified sampling because attrition is a class-imbalanced problem —
only about 16% of employees leave. I used AUC-ROC as the primary metric rather than accuracy,
because accuracy would be misleadingly high if the model just predicted 'No' for everyone.
I also added class_weight='balanced' to handle the imbalance."
